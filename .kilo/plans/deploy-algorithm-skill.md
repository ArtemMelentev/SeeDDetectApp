# План: Создание скилла deploy-algorithm

## Цель
Создать Kilo-скилл `.kilo/skills/deploy-algorithm/SKILL.md`, который автоматизирует внедрение новых версий алгоритма сегментации семян в приложение SeeDDetect.

## Анализ предыдущих сессий

Извлечены правила из трёх сессий внедрения:

### Сессия 1: v1 → v2 (план `shiny-wolf.md`)
- Замена скановой сегментации на paper-masked pipeline
- Портирование `detect_paper_mask`, `crop_to_paper`, нормализации, сегментации v2
- Старые функции переименованы в `_legacy`
- Новые функции получили суффикс `_v2`
- Добавлены `do_shading`, `target_short` параметры
- Fallback: если бумага не найдена → full-frame mask

### Сессия 2: v2 → v3 (план `gentle-falcon.md`)
- Замена bbox-кропа на perspective warp
- Новые функции для quad-геометрии и warp
- Fallback: если warp падает → bbox-crop из v2
- Тесты прошли без изменений

### Сессия 3: release_mode (план `hidden-sailor.md`)
- Добавлен `release_mode` параметр
- В релизе только `black_overlay` с крестиками
- `android_bridge.py` обновлён (передача release_mode), но логика алгоритма не затронута

### Обобщённые правила (см. детали в плане)
1. **Неприкасаемое**: android_bridge.py, публичный контракт analyze_image(), имена артефактов, коды ошибок, release_mode логика, Unicode-safe I/O, тесты
2. **Портируется**: вычислительные хелперы (не GUI/CLI/batch-runner)
3. **Не портируется**: GUI, CLI/argparse, batch-runner
4. **Именование**: старые → `_legacy`, новые → `_v{N}`
5. **Fallback**: обязательно для новых критичных операций
6. **Проверка**: `python -m unittest -q`

## Что будет создано

### Файл: `.kilo/skills/deploy-algorithm/SKILL.md`

Скилл в формате Kilo (YAML frontmatter + Markdown body), содержащий:

1. **Входные данные**: принимает `$ARGUMENTS` — путь до файла алгоритма + опционально название версии
2. **Полный свод правил**: неприкасаемые контракты, что портировать, что нет
3. **Пошаговый процесс из 6 шагов**:
   - Шаг 1: Сохранить исходник в `AlgorithmVersions/`
   - Шаг 2: Проанализировать новый алгоритм (карта функций)
   - Шаг 3: Портировать вычислительные функции в `segment_seeds_scan.py`
   - Шаг 4: Обновить pipeline в `analyze_image()`
   - Шаг 5: Обновить дефолты и комментарии
   - Шаг 6: Проверить тестами
4. **Чеклист самопроверки**
5. **Структурные ориентиры** `segment_seeds_scan.py` (строки ключевых секций)
6. **Пример внедрения** v2→v3 для справки

### Действия при реализации
1. Создать директорию `.kilo/skills/deploy-algorithm/`
2. Записать `SKILL.md` с полным содержимым скилла
