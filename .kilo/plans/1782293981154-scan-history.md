# План: История сканов и результатов

## Цель

Добавить сохранение истории сканов. Каждая запись содержит: оригинальное изображение, обработанное изображение (`black_overlay.jpg` с разметкой крестиками), и полные метрики анализа. История доступна офлайн, переживает удаление исходных файлов из галереи.

## Технический контекст

- **Приложение**: Flutter (Dart 3.3+) + Android (Kotlin + Chaquopy + OpenCV)
- **Текущее состояние**: весь UI в `lib/main.dart` (679 строк), один `StatefulWidget AnalyzScreen`
- **Персистентность**: отсутствует. Результаты живут в `cacheDir/seed_runs/`, автоочистка через 24ч
- **Нет зависимостей** для хранения: ни sqflite, ни Hive, ни SharedPreferences

## Структура хранения

```
{appDocuments}/history/
  index.json                      # массив сводок, сортировка: новые сверху
  20260624_a1b2c3d4/
    original.jpg                  # копия исходного файла (или извлечённое из PDF)
    overlay.jpg                   # black_overlay.jpg из run_dir
    thumbnail.jpg                 # миниатюра 200×200 для списка
    metadata.json                 # полные метрики
  20260624_e5f6g7h8/
    ...
```

### `index.json` — формат одной записи

```json
{
  "id": "20260624_a1b2c3d4",
  "timestamp": "2026-06-24T16:45:30.123",
  "originalFileName": "IMG_20260624_1645.jpg",
  "thumbnailPath": "history/20260624_a1b2c3d4/thumbnail.jpg",
  "seedCount": 42,
  "blackSeedCount": 18,
  "blackToAllRatio": 36.0
}
```

### `metadata.json` — формат

```json
{
  "id": "20260624_a1b2c3d4",
  "timestamp": "2026-06-24T16:45:30.123",
  "originalFileName": "IMG_20260624_1645.jpg",
  "metrics": {
    "seed_count": 42,
    "black_seed_count": 18,
    "all_seed_area_px": 125000,
    "image_area_px": 12189696,
    "black_seed_area_px": 45000,
    "all_seed_ratio_pct": 10.25,
    "black_seed_ratio_pct": 3.69,
    "black_to_all_seed_ratio_pct": 36.0,
    "processing_ms": 1523,
    "image_w": 4032,
    "image_h": 3024,
    "preprocessing": {}
  },
  "files": {
    "original": "original.jpg",
    "overlay": "overlay.jpg",
    "thumbnail": "thumbnail.jpg"
  }
}
```

## Data Flow

```
[Анализ завершён: _result Map]
  │
  ├─→ HistoryService.saveScan(_result)
  │     ├─ 1. Генерируем scanId = DateTime.now + uuid
  │     ├─ 2. Создаём history/{scanId}/
  │     ├─ 3. Копируем оригинал (из _result["image"]) → original.jpg
  │     ├─ 4. Копируем оверлей (из _result["artifacts"]["black_overlay"]) → overlay.jpg
  │     ├─ 5. Генерируем thumbnail.jpg (200×200, decodeImageFromList + Canvas)
  │     ├─ 6. Пишем metadata.json
  │     ├─ 7. Обновляем index.json (вставка в начало массива)
  │     ├─ 8. При ошибке на любом шаге: удаляем history/{scanId}/, НЕ обновляем index.json
  │     └─ 9. Возвращаем успех/ошибку
  │
  └─→ UI: SnackBar «Сохранено в историю» / SnackBar с ошибкой + кнопка «Повторить»
```

При открытии истории:

```
HistoryScreen
  ├─→ HistoryService.loadIndex() → List<HistoryEntry>
  ├─→ ListView.builder
  │     └─→ Dismissible(свайп влево → диалог → удаление)
  │           └─→ Карточка: [миниатюра] | Дата | Всего: N · Чёрных: N (X%)
  │                 └─→ onTap → показать overlay в InteractiveViewer + плашку метрик
  └─→ AppBar: кнопка «Очистить всё» → диалог → HistoryService.deleteAll()
```

## Порядок реализации

1. **Создать `lib/services/history_service.dart`**
   - Класс `HistoryEntry` (id, timestamp, originalFileName, thumbnailPath, seedCount, blackSeedCount, blackToAllRatio)
   - Класс `HistoryService`:
     - `getHistoryDir()` — путь к `{appDoc}/history/`
     - `loadIndex()` — чтение `index.json`, возврат `List<HistoryEntry>`, новые сверху
     - `saveScan(Map<String, dynamic> result)` — полный flow сохранения
     - `deleteEntry(String scanId)` — удаление папки + запись из `index.json`
     - `deleteAll()` — удаление всей `history/` директории
     - `loadMetadata(String scanId)` — чтение `metadata.json` для деталей
   - Генерация миниатюры: `_generateThumbnail(String overlayPath, String thumbnailPath)` — `decodeImageFromList` + Canvas 200×200
   - Метод `_generateScanId()` — `DateTime.now` + `uuid` (использовать встроенный `Uuid` или `DateTime.now().millisecondsSinceEpoch.toRadixString(36)`)

2. **Создать `lib/screens/history_screen.dart`**
   - `HistoryScreen` — `StatefulWidget`
   - `initState` → `_loadHistory()` → `loadIndex()`
   - `_buildEmptyState()` — иконка, текст, кнопка «К анализу» → `Navigator.pop()`
   - `_buildHistoryList()` — `ListView.builder`
   - `_buildScanCard(HistoryEntry)` — карточка с миниатюрой и текстом
   - `Dismissible` с `confirmDismiss` → `showDialog` подтверждения → `deleteEntry()`
   - `onTap` карточки → загрузить `metadata.json` → `_showDetailDialog()`: `InteractiveViewer` с оверлеем + нижняя плашка метрик
   - AppBar: заголовок «История», кнопка корзины → `showDialog` → `deleteAll()`

3. **Изменить `lib/main.dart`**
   - Добавить `import` на `history_service.dart` и `history_screen.dart`
   - Добавить поле `final HistoryService _historyService = HistoryService();`
   - В `_showResult()` или после получения результата: вызвать `_saveToHistory(result)`
   - Метод `_saveToHistory()`: вызывает `_historyService.saveScan()`, показывает SnackBar
   - При ошибке сохранения: `setState` флаг `_saveFailed = true` → в `_buildMetrics()` показать кнопку «Сохранить в историю»
   - В `AppBar`: добавить `actions: [IconButton(icon: Icon(Icons.history), onPressed: _openHistory)]`
   - Метод `_openHistory()`: `Navigator.push(context, MaterialPageRoute(builder: (_) => HistoryScreen(historyService: _historyService)))`

## Особые случаи

1. **Дубликаты**: один и тот же файл, проанализированный дважды → две разные записи с разными scanId
2. **Ошибка диска**: ловим `FileSystemException` в `saveScan()` → удаляем частично созданную папку, возвращаем ошибку → UI показывает SnackBar + кнопку повтора
3. **Отсутствие `index.json`**: первый запуск → `loadIndex()` возвращает пустой список
4. **Битые записи**: при загрузке индекса — если папка `history/{scanId}` не существует, пропускаем запись (не падаем)
5. **Очистка run_dir**: не трогаем, Kotlin сам чистит через 24ч (MainActivity.kt: cleanupOldRunDirectories)
6. **PDF**: в `_result["image"]` уже лежит путь к извлечённому изображению → копируем его как оригинал
7. **Share intent**: flow доходит до того же `_showResult()` → автосохранение срабатывает единообразно
8. **Миниатюра битая**: если генерация не удалась, сохраняем без thumbnail, в списке показываем `overlay.jpg` как fallback

## Валидация

1. **Юнит-тест HistoryService**: создать временную директорию, проверить `saveScan` + `loadIndex` + `deleteEntry` + `deleteAll`
2. **Интеграционный тест**: просканировать изображение, открыть историю, убедиться в наличии записи, открыть детали, удалить запись
3. **Ручная проверка**: удалить исходное фото из галереи, открыть историю — запись и оверлей должны быть доступны
4. **Граничные случаи**: пустая история → placeholder; очистить всё → placeholder; ошибка сохранения → SnackBar + кнопка повтора
